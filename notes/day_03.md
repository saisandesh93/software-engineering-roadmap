## Software Engineering

Studied comprehensions, iterators and generators with a focus on writing more Pythonic and maintainable code.

## Key Takeaways

* Comprehensions can make simple transformations and filtering more concise and readable.
* An iterable is something we can iterate over, while an iterator produces values one at a time.
* `iter()` can create an iterator from an iterable and `next()` retrieves the next value.
* Generators use `yield` to produce values lazily instead of creating the entire result in memory at once.
* Generator expressions are useful when I don't need to create the complete collection immediately.
* Pythonic code is not simply shorter code; readability and choosing the appropriate abstraction are important.
