## Key Takeaways

1. Python looks for variable names according to the LEGB rule:
   Local → Enclosing → Global → Built-in.

2. `*args` allows a function to accept a variable number of positional arguments.

3. `**kwargs` allows a function to accept a variable number of keyword arguments.

4. Mutable default arguments can cause unexpected behaviour because the default object is created once when the function is defined.

5. Python's functions and scope rules are more nuanced than basic function syntax.

6. Hash-based data structures are important for solving DSA problems efficiently.
